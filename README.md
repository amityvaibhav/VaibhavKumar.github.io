# Vaibhav Kumar

Personal academic website.

## Publishing on GitHub Pages

1. Create a repository named `<your-username>.github.io`, public.
2. Upload `index.html`, `.nojekyll`, `README.md` and the `assets` folder.
3. Settings -> Pages -> Deploy from a branch, `main`, `/ (root)`.

## Editing

Open `index.html` on GitHub, click the pencil icon, edit, commit.
Keep the "Currently" section near the top up to date; it is the part that shows the site is alive.
